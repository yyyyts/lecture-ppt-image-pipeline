# 讲课 PPT 图片生成 Skill

将论文、书本或其他教学材料整理为讲课 PPT：先编写逐页大纲和讲稿，生成整套 16:9 缩略图拼图，再逐页生成幻灯片视觉稿并汇总为 PDF。

## 使用流程

1. 提供材料，并说明目标听众和整体视觉风格。若缺少风格或听众，skill 会先询问。
2. 查看逐页大纲、页面要点、视觉方向和讲稿摘要；明确确认后才生成缩略图。
3. 查看整套缩略图拼图；明确确认后才逐页生成视觉稿和 PDF。
4. 若提出修改，受影响的阶段会重新提交确认。未回复不会被视为确认。

未指定语言时，默认使用中文。用户明确指定其他语言时，以该要求为准。专有名词、公式、引文和数据关系应以原材料为准。

## 安装

将本仓库放入个人 Codex skills 目录，并保持以下结构：

```text
lecture-ppt-image-pipeline/
├── SKILL.md
└── references/
    └── prompts.md
```

然后在任务中调用 `$lecture-ppt-image-pipeline`，提供论文、书本章节或其他教学材料。

## 输出与限制

默认流程生成大纲、讲稿、拼图、逐页图片和图片式 PDF。图片生成的文字可能出现错误，使用时应按结构化内容计划逐页核对。PDF 中的图片页面不等于可编辑 PPTX；如需可编辑版本，应另行制作。
